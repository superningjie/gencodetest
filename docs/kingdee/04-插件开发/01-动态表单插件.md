## 4. 事件总览

| 事件名称 | 触发时机 | 常用场景 |
|---------|---------|---------|
| setPluginName | 设置插件名称 | 插件初始化 |
| preOpenForm | 打开表单前 | 权限校验 |
| loadCustomControlMetas | 加载自定义控件 | 动态控件 |
| setView | 设置视图 | 界面调整 |
| initialize | 初始化 | 数据准备 |
| createNewData | 创建新数据 | 默认值设置 |
| afterCreateNewData | 创建后 | 关联数据处理 |
| beforeBindData | 绑定数据前 | 数据转换 |
| afterBindData | 绑定数据后 | 界面调整 |
| beforeItemClick | 点击前 | 权限控制 |
| itemClick | 点击时 | 自定义逻辑 |
| beforeDoOperation | 操作前 | 校验逻辑 |
| afterDoOperation | 操作后 | 后续处理 |
| propertyChanged | 属性变更 | 联动处理 |
| beforeClosed | 关闭前 | 保存确认 |
| destory | 销毁 | 资源释放 |
