案例说明：使用EXPORT关键字，在一个公式中同时输出多个考勤项目结果。

示例说明：某项目不需要旷工异常，只有缺卡。因此可以在公式中将旷工异常清除掉，再生成缺卡异常。

  


**公式代码**  
---  
//当存在旷工时长时 IF AE[旷工时长] != 0THEN //记下旷工时长 NUM t = AE[旷工时长] //将旷工时长调整为0 AE[旷工时长] = 0 EXPORT AE[旷工时长] //将旷工时长记为缺卡时长 RESULT = tELSE RESULT = NULL ENDIF   
  
  


![](https://vip.kingdee.com/download/0109f3aa939b58f3423bb03b237383ce8309.png)

  


代码解释：

1、先判断是否存在旷工，即旷工时长不等0（或大于0）；

2、记下旷工时长，然后将旷工时长调整为0并通过EXPORT输出；

3、将原旷工时长赋值给结果项目进行输出。
