新特性介绍

  * 列表用插件打开默认合计功能以及去掉默认排序来优化性能



特性效果展示

列表之前的合计是在页面数据加载时直接计算的，当页面数据量较大时会出现加载较慢的情况，并对服务器造成较大压力，所以合计的计算目前优化为需要用户进行点击来进行，如下图，列表数据底部会出现“计算合计”

![](https://vip.kingdee.com/download/0100876bb86eb75f459d9f520f692d60b980.png)

如果确认数据量较小，不会对服务器造成较大压力，可以通过插件方式打开初始加载就计算合计功能，代码示例如下：
    
    
            @Override
    	public void sumDataLoadOnFirstSet(SumDataLoadOnFirstSetEvent args) {
    		args.setSumDataLoadOnFirst(true);
    		super.sumDataLoadOnFirstSet(args);
    	}

  


对排序的优化：

  


列表会默认给单据增加单据主键倒叙作为排序字段，如果有分录会带上seq字段的倒叙，这样保证一个单据的数据排在一起，同时保证分录是有序的，但是如果数据量较多的情况，如果缺少seq索引，会有较严重的性能问题，如果用户可以接受分录无序，可以通过如下开关来关掉默认排序，关掉后主键倒叙还是生效的
