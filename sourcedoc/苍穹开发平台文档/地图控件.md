    ## 4.3 业务属性
    
    | 属性名 | 类型 | 说明 | PC | Mobile |
    | --- | --- | --- | --- | --- |
    | 启用搜索 | 复选框 | 1、PC端默认开启/true，是否显示地图左上角的搜索框（插件设置）<br>2、移动端默认关闭/false，设计器中有对应”启用搜索“属性支持可视化配置，开启后地图显示搜索框 | V4.0及以上 | V7.0.1及以上 |
    | 标记是否可拖动 | 复选框 | 默认false，属性打开后可用鼠标拖动地图上的位置标记（插件设置） | V4.0及以上 | V5.0.023及以上 |
    | 经纬度标记 | 文本 | 根据经纬度在地图上标记一个点（插件设置） | V4.0及以上 | V4.0及以上 |
    | 地址标记 | 弹框选择 | 根据一个地址信息在地图上标记一个点（插件设置） | V4.0及以上 | V4.0及以上 |
    
    # 5 地图控件接口说明
    
    * 控件方法
    
    | 方法名 | 说明 | 参数 |
    | --- | --- | --- |
    | selectPoint | 设置前端地图控件选中某个节点(节点包含具体信息) | {“title”:“金蝶软件”,“point”:{“lng”:113.96624,“lat”:22.576339},“address”:“南山科技园科技南12路”,“city”:“深圳市”,“province”:"广东省”} |
    | selectAddress | 设置前端地图标记某个地址,以节点形式 | {detailAddress:广东省深圳市南山区金蝶大厦A座} |
    
    * 功能说明
    
    | 功能名 | 说明 |
    | --- | --- |
    | 搜索 | 地图左上角有搜索框，使用该搜索框可以根据用户录入关键字搜索出多个结果，鼠标点击单个结果地图会自定定位并标记 |
    | 根据经纬度定位 | 后端插件调用该方法传送经纬度信息，前端自动根据该信息在地图上定位并标记 |
    | 根据具体地址定位 | 后端插件调用该方法传送地址信息，前端自动根据该信息在地图上定位并标记 |
    
    * 前端回传定位信息
    
    点击地图上某个标记节点，前端会自动往后端发送该标记信息，数据示例如下:
    ```js
    [{"key":"mapcontrolap","methodName":"select","args":[{"latitude":22.53979005313571,"longitude":113.96133709676266,"province":"广东省","city":"深圳市","district":"南山区","name":"","address":"金蝶软件园内,金蝶大厦附近25米","addressdetail":"广东省深圳市南山区高新南七道 金蝶软件园","origin":"广东省深圳市南山区金蝶大厦A座"}],"postData":[{},[]]}]
    
    ```
    
    * 数据结构示例
    
    ```js
    {
        "title":"金蝶软件(民德路)",
        "point":{"lng":114.04663,"lat":22.624036},
        "address":"民治大道317东边商务大楼3059室",
        "city":"深圳市",
        "province":"广东省"
    }
    
    ```
    
    * 调用示例
    
    ```java
    public void do() {
        *// 设置显示隐藏搜索框（通用u指令）*
        Map<String, Object> dataMap = new HashMap<>();
        dataMap.put("showSearchBox", false); *//属性名称+值*
        dataMap.put("k", "控件id");
        IClientViewProxy proxy = this.getView().getService(IClientViewProxy.class);
        proxy.addAction(ClientActions.updateControlStates, dataMap);
    
        *// 设置是否可拖动地图标记*
        Map<String, Object> dataMap = new HashMap<>();
        dataMap.put("canMarkerDraggble", true); *//属性名称,值*
        dataMap.put("k", "控件id");
        IClientViewProxy proxy = this.getView().getService(IClientViewProxy.class);
        proxy.addAction(ClientActions.updateControlStates, dataMap);
    
        *// 设置地图根据经纬度标记某个位置*
        MapControl mapCtl = this.getView().getControl("控件id");
        mapCtl.selectPoint(MapSelectPointOption对象参数示例)  *//MapSelectPointOption：经纬度封装对象*
    
        *// 设置地图根据地址标记某个位置*
        MapControl mapCtl = this.getView().getControl("控件id");
        mapCtl.selectAddress("广东省深圳市南山区科技园金蝶软件");
    }
    
    
    
    ```
    具体案例请参考：[地图控件 ](https://developer.kingdee.com/article/409035644032012032)

## 4.3 业务属性

属性名 | 类型 | 说明 | PC | Mobile  
---|---|---|---|---  
启用搜索 | 复选框 | 1、PC端默认开启/true，是否显示地图左上角的搜索框（插件设置）  
2、移动端默认关闭/false，设计器中有对应”启用搜索“属性支持可视化配置，开启后地图显示搜索框 | V4.0及以上 | V7.0.1及以上  
标记是否可拖动 | 复选框 | 默认false，属性打开后可用鼠标拖动地图上的位置标记（插件设置） | V4.0及以上 | V5.0.023及以上  
经纬度标记 | 文本 | 根据经纬度在地图上标记一个点（插件设置） | V4.0及以上 | V4.0及以上  
地址标记 | 弹框选择 | 根据一个地址信息在地图上标记一个点（插件设置） | V4.0及以上 | V4.0及以上  
  
# 5 地图控件接口说明

  * 控件方法

方法名 | 说明 | 参数  
---|---|---  
selectPoint | 设置前端地图控件选中某个节点(节点包含具体信息) | {“title”:“金蝶软件”,“point”:{“lng”:113.96624,“lat”:22.576339},“address”:“南山科技园科技南12路”,“city”:“深圳市”,“province”:"广东省”}  
selectAddress | 设置前端地图标记某个地址,以节点形式 | {detailAddress:广东省深圳市南山区金蝶大厦A座}  
  
  * 功能说明

功能名 | 说明  
---|---  
搜索 | 地图左上角有搜索框，使用该搜索框可以根据用户录入关键字搜索出多个结果，鼠标点击单个结果地图会自定定位并标记  
根据经纬度定位 | 后端插件调用该方法传送经纬度信息，前端自动根据该信息在地图上定位并标记  
根据具体地址定位 | 后端插件调用该方法传送地址信息，前端自动根据该信息在地图上定位并标记  
  
  * 前端回传定位信息



点击地图上某个标记节点，前端会自动往后端发送该标记信息，数据示例如下:
    
    
    [{"key":"mapcontrolap","methodName":"select","args":[{"latitude":22.53979005313571,"longitude":113.96133709676266,"province":"广东省","city":"深圳市","district":"南山区","name":"","address":"金蝶软件园内,金蝶大厦附近25米","addressdetail":"广东省深圳市南山区高新南七道 金蝶软件园","origin":"广东省深圳市南山区金蝶大厦A座"}],"postData":[{},[]]}]
