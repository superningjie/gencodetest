    # 4 属性说明
    ## 4.1 通用属性
    >通用属性包含字段和控件的一些公有的属性，如宽高，帮助文本等等。请参考[通用属性](https://vip.kingdee.com/article/215559076720798976)
    ## 4.2 样式属性
    >样式属性是每个控件在设计器右侧样式栏可以设置的属性，请参考[样式属性](https://vip.kingdee.com/article/252017936767406336)
    ## 4.3 业务属性
    
    | 设计器属性名 | 类型 | 运行时参数名 | 默认值 | 说明 | PC |
    | --- | --- | --- | --- | --- | --- |
    | 自动保存 | boolean | autosave | false | 停止操作编辑器两秒后，会自动保存一次已经编辑的内容，保存的内容通过自定义事件发送到后端，后端需要监听“customEvent“事件获取数据 | V4.0及以上 |
    | 锁定可打印预览 | boolean | ilp | false | 锁定情况下可打印和预览 | V4.0及以上 |
    | 设置功能 | object | toolbarItems | - | 配置自定义的富文本工具栏项，详情见[富文本控件支持自定义工具栏](https://vip.kingdee.com/article/167943292972811008) | V4.0及以上 |
    | 模式 | number | model | 0 | 可配置编辑模式和只读模式，用于富文本的编辑和展示功能，详见4.3.1 | V5.0.002及以上 |
    | 最大内容大小 | number | maxRichTextLength | 20 | 设置富文本编辑器最大内容，单位是MB，超出内容会被截断 | V6.0.0及以上 |
    
    ### 4.3.1 模式
    富文本编辑器的模式分为编辑模式和只读模式。编辑模式时，可供用户输入编辑富文本内容。只读模式下不可编辑，且高度自适应，会根据内容撑开，不会出现滚动条。
    ### 4.3.2 内容加密传输
    5.0.023以下版本，支持关闭内容加密传输；
    5.0.023及以上版本，富文本编辑器内容默认经过base64编码传输，避免出现网络拦截。
    ## 4.4 二开属性
    
    | 属性名 | 类型 | 默认值 | 说明 | PC |
    | --- | --- | --- | --- | --- |
    | imageMaxSize | number | 3072000 | 设置上传图片的最大尺寸 | V4.0及以上 |
    | useRelativePath | boolean | false | 上传图片的路径是否使用相对路径。默认使用绝对路径，为true时，新上传的图片将使用相对路径 | V6.0.3及以上 |
    | configExt | object | - | 扩展字体和字体大小 | V6.0.12及以上 |
    
    ### 4.4.1使用示例
    ```
    // 更新业务数据方式     
    Map<String, Object> dataMap = new HashMap<>();     
    dataMap.put("useRelativePath", true); //设置上传图片的路径使用相对路径    
    dataMap.put("k", "控件id");         
    proxy.addAction(ClientActions.updateControlStates, dataMap); 
    
    // 更新元数据方式
    Map<String, Object> fieldMap = new HashMap<>(); 
    fieldMap.put(ClientProperties.useRelativePath, true); //设置上传图片的路径使用相对路径
    this.getView().updateControlMetadata("fieldname", fieldMap);
    
    
    ```
    
    # 5 富文本编辑器接口介绍
    
    * 插件设置和获取富文本内容
    
    ```java
    RichTextEdit edit = this.getView().getControl("控件标识");*// 设置内容*
    edit.setText("要设置的内容");
    *// 获取内容*
    edit.getText();
    
    ```
    
    * 开启自动保存后，插件需要再customEvent中获取富文本的内容
    
    ```java
    @Overridepublic void customEvent(EventObject e) {
      super.customEvent(e);
      String args = e.getEventArgs();  *// 富文本内容*
    }

5.0.023及以上版本，富文本编辑器内容默认经过base64编码传输，避免出现网络拦截。

## 4.4 二开属性

属性名 | 类型 | 默认值 | 说明 | PC  
---|---|---|---|---  
imageMaxSize | number | 3072000 | 设置上传图片的最大尺寸 | V4.0及以上  
useRelativePath | boolean | false | 上传图片的路径是否使用相对路径。默认使用绝对路径，为true时，新上传的图片将使用相对路径 | V6.0.3及以上  
configExt | object | - | 扩展字体和字体大小 | V6.0.12及以上
