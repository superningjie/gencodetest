    # 变更记录
    
    | 产品版本 | 更新内容            | 更新日期   |
    | -------- | ------------------- | ---------- |
    | V7.0.9   | 图表控件的 ECharts 版本已从 4.9 升级至 5.5。此次升级涵盖‌性能优化、功能增强及视觉<br>调整‌，旨在提升图表控件的稳定性、交互体验与视觉表现。 | 2025-04-03 |
    
    
    # 1 用户场景
    
    EChartsV5支持了非常多的新特性，不仅是视觉上的提升，交互上的体验以及性能的优化都有非常大的改进
    同时option的配置项也新增了很多V5的配置，用户现在可以使用V5的配置项更加灵活的配置图表
    
    # 2 功能介绍
    
    新特性请参考：
    [ECharts 5 特性介绍 - 版本特性 - 入门篇 - 使用手册 - Apache ECharts](/tolink?target=https://echarts.apache.org/handbook/zh/basics/release-note/v5-feature)
    
    # 3 视觉更新
    
    本次更新，不同类型图表的默认样式也发生了迭代变化，部分示例如下。
    饼图（piechartap）‌：在升级后，饼图去掉了白色分割线，使得图表更加简洁和现代。
    ![image.png](/download/0100c671d5b8c0774f4e950e246a0867dd48.png)
    饼图（piechartap）‌：当数据为空时，系统会自动添加一个提示元素，提示用户当前无数据，这一变化提升了用户体验。
    ![image.png](/download/0100fc6a687407d0427c8c45f0ab48aa4d0a.png)
    饼图（piechartap）‌：鼠标悬停提示信息更加细致和准确，方便用户获取更多详细信息。
    ![image.png](/download/0100972d096836e8492eae38cec4c07f36ca.png)
    ‌雷达图（radarchartap）‌：默认样式有所变化，使图表显示更加美观和直观。
    ![image.png](/download/010045ef35230344490e945626e5d9d131d5.png)
    仪表盘（gaugechartap）：默认样式有所变化，线条更加清晰，视觉更加美观简约。
    ![image.png](/download/01002ab396796fb14fae963f8a5f22ff3c86.png)
    点线图（pointlinechartap）‌：默认样式变化，实线变为虚线，增强了图表的可读性。
    ![image.png](/download/01005363072c457f409783fa9f7eb770977f.png)
    
    # 4 适用版本
    
    金蝶云苍穹BOS_V7.0.9及以上
