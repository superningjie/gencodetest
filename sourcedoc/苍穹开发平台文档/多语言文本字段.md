# 5.功能详情

## 5.1 获取光标

多语言字段支持获取文本框内光标停留的位置，以便在固定位置插入输入内容。当失焦后，向后端发送的请求中，会携带该字段失焦时的光标位置（`cursorIndex`）。适用于金蝶云·苍穹 V8.0.1及以上版本。

# 6 多语言文本接口介绍

## 6.1 控件编程模型

多语言文本字段，派生自文本字段，采用与文本字段相同的控件编程模型[TextEdit](https://vip.kingdee.com/article/228981705241898752)。

## 6.2 数据模型

多语言文本字段的属性对象类型为MuliLangTextProp，派生自TextProp，存储String类型字段值：
    
    
    package kd.bos.entity.property;
    public class MuliLangTextProp extends TextProp {}
    
    

_说明：_  
_多语言文本字段能同时存储多种语言的字段值。在数据模型中，它的值是ILocaleString类型。这是一种按语言存储文本值的数据字典。_

## 6.3 插件事件

多语言文本字段，继承了字段值改变事件，未增加其他插件事件。
