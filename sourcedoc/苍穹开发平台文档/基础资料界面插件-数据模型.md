1 插件介绍

基础资料界面插件可以通过系统封装的数据模型，访问界面数据

  


2 插件接口和实现类

基础资料数据模型接口为**IBaseModel** ，派生自单据界面数据模型接口[IBillModel](https://vip.kingdee.com/article/223131905477700864)。
    
    
    package   kd.bos.entity.datamodel;
    public interface IBaseModel extends   IBillModel {
    }
