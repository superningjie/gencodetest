    上传按钮与上传配置是配套使用的。

    # 5 按钮接口介绍
    ## 5.1 控件编程模型
    ### 5.1.1 控件编程模型定义
    按钮的控件编程模型是Button，派生自控件基类Control：
    ```java
    package kd.bos.form.control;
    public class Button extends Control implements ISuportClick {
    
    ```
    插件可以通过如下代码，获取到按钮的控件编程模型实例：
    ```java
    Button button1 = this.getView().getControl(KEY_BUTTON1);
    
    
    ```
    
    ### 5.1.2 控件方法清单
    按钮的控件编程模型Button，继承了控件基类Control的方法，新增了如下的控制方法：
    
    | 方法 | 说明 |
    | --- | --- |
    | getOperationKey | 按钮绑定的操作 |
    | setOperationKey | 设置绑定的操作 |
    
    
    ## 5.2 插件事件
    按钮控件，提供如下插件事件：
    
    | 事件 | 触发时机 |
    | --- | --- |
    | beforeClick | 用户点击按钮时，触发此事件 |
    | click | 用户点击按钮时，触发此事件 |
    | beforeItemClick | 暂未触发 |
    | itemClick | 用户点击按钮所带的子按钮时，触发此事件 |
    | upload | 文件上传界面关闭时后，触发此事件 |
    | afterUpload | 同upload事件，比之稍晚触发 |
    | remove | 在文件上传界面，删除已上传文件时，触发此事件 |
    | afterRemove | 同remove事件，比之稍晚触发 |

# 5 按钮接口介绍

## 5.1 控件编程模型

### 5.1.1 控件编程模型定义

按钮的控件编程模型是Button，派生自控件基类Control：
    
    
    package kd.bos.form.control;
    public class Button extends Control implements ISuportClick {
    
    

插件可以通过如下代码，获取到按钮的控件编程模型实例：
    
    
    Button button1 = this.getView().getControl(KEY_BUTTON1);
    
    
    

### 5.1.2 控件方法清单

按钮的控件编程模型Button，继承了控件基类Control的方法，新增了如下的控制方法：

方法 | 说明  
---|---  
getOperationKey | 按钮绑定的操作  
setOperationKey | 设置绑定的操作  
  
## 5.2 插件事件

按钮控件，提供如下插件事件：

事件 | 触发时机  
---|---  
beforeClick | 用户点击按钮时，触发此事件  
click | 用户点击按钮时，触发此事件  
beforeItemClick | 暂未触发  
itemClick | 用户点击按钮所带的子按钮时，触发此事件  
upload | 文件上传界面关闭时后，触发此事件  
afterUpload | 同upload事件，比之稍晚触发  
remove | 在文件上传界面，删除已上传文件时，触发此事件  
afterRemove | 同remove事件，比之稍晚触发

# 5 按钮接口介绍

## 5.1 控件编程模型

### 5.1.1 控件编程模型定义

按钮的控件编程模型是Button，派生自控件基类Control：
    
    
    package kd.bos.form.control;
    public class Button extends Control implements ISuportClick {
    
    

插件可以通过如下代码，获取到按钮的控件编程模型实例：
    
    
    Button button1 = this.getView().getControl(KEY_BUTTON1);
    
    
    

### 5.1.2 控件方法清单

按钮的控件编程模型Button，继承了控件基类Control的方法，新增了如下的控制方法：

方法 | 说明  
---|---  
getOperationKey | 按钮绑定的操作  
setOperationKey | 设置绑定的操作  
  
## 5.2 插件事件

按钮控件，提供如下插件事件：

事件 | 触发时机  
---|---  
beforeClick | 用户点击按钮时，触发此事件  
click | 用户点击按钮时，触发此事件  
beforeItemClick | 暂未触发  
itemClick | 用户点击按钮所带的子按钮时，触发此事件  
upload | 文件上传界面关闭时后，触发此事件  
afterUpload | 同upload事件，比之稍晚触发  
remove | 在文件上传界面，删除已上传文件时，触发此事件  
afterRemove | 同remove事件，比之稍晚触发
