    # 6 多选下拉列表接口介绍
    ## 6.1 控件编程模型
    多选下拉框字段，派生自下拉框字段，与下拉框字段采用相同的控件编程模型[ComboEdit](https://vip.kingdee.com/article/229238321971860224)。
    ComboEdit可以控制下拉选项的锁定属性，kd.bos.form.field.ComboEdit#setComboItems 这个方法，该方法的入参是一个ComboItem集合，ComboItem提供了一个属性disable，代表是否可选，插件只需要调用控件的这个方法传入参数即可；
    ## 6.2 数据模型
    多选下拉框的属性对象为MulComboProp类型，派生自ComboProp，存储下拉选项值，String类型：
    ```java
    package kd.bos.entity.property;
    public class MulComboProp extends ComboProp {
    
    ```
    多选下拉框字段取值、赋值方法，与下拉框字段相同，多选下拉框可以选择多个选项，已选的多个选项值使用逗号”,”分割。
    
    ## 6.3 插件事件
    多选下拉框字段，继承了字段值改变事件，未增加其他插件事件。
    
    ## 6.4 动态更新选项
    在V7.0.7及以上版本，支持动态更新选项，包括：修改选项名称/可见性/锁定性，增加/删除选项等功能。
    **使用示例：**
    修改：
    ```java
    kd.bos.form.field.ComboEdit#updateComboItems;
    
    ComboEditcomboEdit=this.getView().getControl(控件标识);
    List<ComboItemUpdateDto>updateDtos = newArrayList<>(); // 待修改的选项列表
    ComboItemUpdateDtoitem = newComboItemUpdateDto("value0");
    item.setDisable(true);//修改是否置灰
    item.setCaption(newLocaleString("测试名称"));//修改名称
    ComboItemUpdateDtoitem1=newComboItemUpdateDto("value1");
    item1.setItemVisible(false);//修改可见性
    updateDtos.add(item);
    updateDtos.add(item1);
    comboEdit.updateComboItems(updateDtos);
    
    
    ```
    新增：
    ```java
    kd.bos.form.field.ComboEdit#insertComboItems
    
    ComboEditcomboEdit=this.getView().getControl(控件标识);
    List<ComboItem>newItems = newArrayList<>(); //构造需要插入的选项列表
    // 根据需要设置item的值
    ComboItem item = new ComboItem();
    // 加入待插入列表中
    newItems.add(item);
    // ComboInsertDirection.BEFORE
    comboEdit.insertComboItems(newItems,"value0", ComboInsertDirection.AFTER); //在选项值为value0的选项的后方插入，若需要从前方插入使用
    //insertPos参数若不设置则默认在最后一个选项的后方插入，此时插入方向不生效
    
    ```
    删除：
    ```java
    kd.bos.form.field.ComboEdit#deleteComboItems
    
    ComboEditcomboEdit=this.getView().getControl(控件标识);
    List<String> deleteValues = newArrayList<>(); // 需要删除的选项value列表
    deleteValues.add("value0");
    deleteValues.add("value1");
    comboEdit.deleteComboItems(deleteValues);
    
    
    ```

    ```
    增加：
    ```js

         "methodname":"updateComboItemData",
         "args":[
             ['insert', 
             [
              ['4',{"zh_CN": "选项一",..}, null, true, false],
              ['5',{"zh_CN": "选项二",..}, null, true, false]，
              ['6',{"zh_CN": "选项三",..}, null, false, false]
             ],
             '4',
             'before | after'
            ]
         ]
       ]
    }

# 6 多选下拉列表接口介绍

## 6.1 控件编程模型

多选下拉框字段，派生自下拉框字段，与下拉框字段采用相同的控件编程模型[ComboEdit](https://vip.kingdee.com/article/229238321971860224)。  
ComboEdit可以控制下拉选项的锁定属性，kd.bos.form.field.ComboEdit#setComboItems 这个方法，该方法的入参是一个ComboItem集合，ComboItem提供了一个属性disable，代表是否可选，插件只需要调用控件的这个方法传入参数即可；

## 6.2 数据模型

多选下拉框的属性对象为MulComboProp类型，派生自ComboProp，存储下拉选项值，String类型：
    
    
    package kd.bos.entity.property;
    public class MulComboProp extends ComboProp {
    
    

多选下拉框字段取值、赋值方法，与下拉框字段相同，多选下拉框可以选择多个选项，已选的多个选项值使用逗号”,”分割。

## 6.3 插件事件

多选下拉框字段，继承了字段值改变事件，未增加其他插件事件。

## 6.4 动态更新选项

在V7.0.7及以上版本，支持动态更新选项，包括：修改选项名称/可见性/锁定性，增加/删除选项等功能。  
**使用示例：**  
修改：
    
    
    kd.bos.form.field.ComboEdit#updateComboItems;
    
    ComboEditcomboEdit=this.getView().getControl(控件标识);
    List<ComboItemUpdateDto>updateDtos = newArrayList<>(); // 待修改的选项列表
    ComboItemUpdateDtoitem = newComboItemUpdateDto("value0");
    item.setDisable(true);//修改是否置灰
    item.setCaption(newLocaleString("测试名称"));//修改名称
    ComboItemUpdateDtoitem1=newComboItemUpdateDto("value1");
    item1.setItemVisible(false);//修改可见性
    updateDtos.add(item);
    updateDtos.add(item1);
    comboEdit.updateComboItems(updateDtos);
    
    
    

新增：
    
    
    kd.bos.form.field.ComboEdit#insertComboItems
    
    ComboEditcomboEdit=this.getView().getControl(控件标识);
    List<ComboItem>newItems = newArrayList<>(); //构造需要插入的选项列表
    // 根据需要设置item的值
    ComboItem item = new ComboItem();
    // 加入待插入列表中
    newItems.add(item);
    // ComboInsertDirection.BEFORE
    comboEdit.insertComboItems(newItems,"value0", ComboInsertDirection.AFTER); //在选项值为value0的选项的后方插入，若需要从前方插入使用
    //insertPos参数若不设置则默认在最后一个选项的后方插入，此时插入方向不生效
