    # 技巧一  自定义控件嵌入表单
    ** **
    ## 背景
    很多小伙伴会问到自定义控件如何使用苍穹内部的标准控件，这里给出的答复是：
    自定义控件暂不支持使用平台标准控件！
    自定义控件暂不支持使用平台标准控件！
    自定义控件暂不支持使用平台标准控件！
    但是自定义控件支持使用标准表单，怎么使用？请往下看
     
    ## 如何使用
    首先要明确两个概念
    1、elementId：自定义控件里面的元素id，也就是你需要把表单插入到自定义控件的某个节点元素的id
    2、targetKey：自定义控件id
    自定义控件嵌入表单是通过showForm指令的方式，类型为InContainer
    插件示例：
    ```java
    FormShowParameter parameter = new FormShowParameter();
    parameter.setFormId(formId);
    parameter.setShowTitle(false);
     
    parameter.getOpenStyle().setShowType(ShowType.InContainer);
    parameter.getOpenStyle().setTargetKey('自定义控件id');
     
    Map<String, String> customParams = new HashMap<>();
    customParams.put("elementId", '自定义控件里面的元素id');
    parameter.getOpenStyle().setCustParam(customParams);
     
    this.view.showForm(parameter);
    
    ```
     
    # 技巧二：自定义控件多语言方案
    ## 如何使用
    ### 1、在KDApi.register设置开启多语言
     
    ```js
    /*
     * KDApi.register新增第三个参数：config，object类型，没有传入时默认为空
     * isMulLang：是否使用多语言， 默认为false
    */
    KDApi.register('dellabel', MyComponent, {
     isMulLang: true
    })
    
    ```
     
    ### 2、新建翻译词条JSON文件
    自定义控件根目录下新建lang文件夹，lang文件夹下面新建zh_CN.json和en_US.json，用于表示多语言的文本。内容例如，zh_CN.json：{  "steps.key0001": "简单的步骤条" }，en_US.json：{"steps.key0001": "simple step bar"}。
    在控件下建一个lang目录
    ![image.png](/download/0100491eb6c9350d42b6a5cb9228ae2cb914.png)
    
    在lang文件夹下新建zh_CN.json文件
    ![image.png](/download/0100bc393e83e7a5484aa9edef4e1200640a.png)
     
    ### 3、使用KDApi.getLangMsg(model, key) 获取对应的文本
    将index.js的中文词条抽出，放在zh_CN.json中，以下用自定义控件dellabel为例：
    代码中有中文词条”标签“，则在zh_CN.json文件中这样子写：
    ```js
    {
     "dellabel.key0001": "标签1", // 假如这是第一个词条
     "dellabel.key0002": "标签2" // 假如这里有第二个词条
     "dellabel.key0003": "标签3{date}" // 假如这里有第三个词条，且词条里面含有一个变量date
     "dellabel.key0004": "标签4{date}, {text}" // 假如这里有第四个词条，且词条里面含有两个变量：date和text
    }
    
    ```
    在代码里，词条的位置在这：
    ![image.png](/download/0100055c43e9843f40baa41999ea981febe3.png)
    则需要将“标签”改成KDApi.getLangMsg(model, 'dellabel.key0001')。
     
    ```js
    var updateHtml = function(model, props){
     var lang = model.lang // 获取自定义控件所在单据语言环境，默认中文
     var template = '<div class="hr-delLabel">' +
     '<div class="hr-delLabel-text">' +
     '<%= text %>' +
     '</div>' +
     '<div class="hr-delLabel-icon"></div>' +
     '</div>';
     var result = KDApi.getHTMLStringBytemplate(template, {
     text: props.data && props.data['text'] ? props.data['text'] : props.configItems ? props.configItems[0].value : KDApi.getLangMsg(model, 'dellabel.key0001')
     /*
     * KDApi.getLangMsg(model, 'dellabel.key0003', { date: new Date() }),对应第三个词条"dellabel.key0003": "标签3{date}"
     * KDApi.getLangMsg(model, 'dellabel.key0004', { date: new Date(), text: '文字内容' })对应第四个词条"dellabel.key0004": "标签4{date}, {text}"
     */
     })
     model.dom.innerHTML = result;
     initEvent(model, props);
    }
    
    ```
     
    # 技巧三：自定义控件本地调试
    ## 如何使用
    在请求头的query部分末尾加上kdcus_cdn=http://localhost:3001，如果有hash，则在hash末尾也加上，就可以加载你本地写的自定义控件的代码，开发过程中无需打包上传，也无需修改代码后重启整个服务，方便快捷。
     
    例如：
    ![image.png](/download/0100ecccfa9a543749b99dfdf0045ba7e7eb.png)
    改为：
    ![image.png](/download/0100b3fa48b73e4f4c3faa57f3a1943921c3.png)
     
    http://localhost:3001 这里的url由你本地启动的服务决定，这里只是举例。下面将使用NodeJS建立一个本地静态资源服务器。
    ### 1、使用NodeJS的express模块起一个静态资源服务
    ```js
    // server.js
    const express = require("express"); // npm i --save express
    const app = express();
    const path = require('path')
    const serveIndex = require('serve-index'); // npm i --save serve-index
     
    //设置跨域访问
    app.all('*', function (req, res, next) {
     // 设置可以跨域访问的域名，比如https://feature.kingdee.com:2024
     res.header('Access-Control-Allow-Origin', 'https://feature.kingdee.com:2024');
     res.header('Access-Control-Allow-Credentials', true);
     res.header('Access-Control-Allow-Headers', 'Content-Type,Content-Length, Authorization, Accept,X-Requested-With')
     res.header('Access-Control-Allow-Methods', 'PUT,POST,GET,DELETE,OPTIONS');
     res.header('Content-Type', 'text/css;text/javascript;text/html;application/json;application/x-img');
     next()
    });
     
    // 以下两行代码设置public文件夹为静态资源文件夹，访问http://localhost:3001就可以访问到public文件夹
    app.use('/', express.static(path.join(__dirname, './src/web')));
    app.use('/', serveIndex(path.join(__dirname, './src/web'), {'icons': true}));
     
    // 设置监听3001端口，可以依据具体情况自行修改
    app.listen(3001, () => { // 默认为localhost（本地主机）; 端口号3001
     console.log("CustomControl Static Server is Running!")
    })
    
    
    ```
    
    ### 2、通过nodemon启动server.js
    服务文件和静态资源文件修改，就会自动重启服务
    ```js
    npm install -D nodemon
    nodemon server.js
    
    ```
     
    ### 3、将自定义控件的目录放在“src/web/isv/开发商标识/领域标识/”下
    可以根据开发商标识、领域标识自行建立对应命名的文件夹
    注意：版本v4.0.004或更高版本的标准标定对isv目录做了调整，kingdee目录调整为与isv目录同级。因此kingdee开发商只需要把文件放置在`src/web/kingdee/领域标识/` 目录下，但是如果是低版本，则需要把文件放在`src/web/isv/开发商标识/领域标识/`
    
    # 技巧四：自定义控件支持自定义事件
    ## 背景
    针对不同场景的业务数据传输，可自定义传输给自定义控件所使用的事件名称和数据内容。
    例如你想在点击某个按钮后，让自定义控件接收到后端发送的指令修改自定义控件的某个值，可以按照如下方式实现。
    同时通过该接口也可以实现前端数据差量化更新，不依赖服务端的`setData`接口。
    ## 如何使用
    后端插件 - 通过invokeControlMethod指令调用自定义事件：
    ![image.png](/download/0100ddfd2cb76c484e96854135165ae15c03.png)
    
    前端页面 - 网络请求响应，数据格式如下图：
    ![image.png](/download/0100de09008a647d416994f975841b469918.png)
    
    自定义控件 - 内部获取数据（响应自定义事件，通过`handleDirective`接口）处理如下：
    ```javascript
    HelloWord.prototype = {
      _setModel: function (model) {
         this.model = model
      },
      init: function () {},
      update: function () {},
      handleDirective: function(customProps, methodname, args) {
      // 这里的methodname 对应的是指令发过来定义的methodname，可根据方法名拿到对应的参数args
      }
    }
    ```
    **注**：`handleDirective`生命周期需要自定义控件正确加载dom元素后才能接受指令（init方法内需要给model.dom设置正确的页面元素，**不能为空**）

## 背景

自定义控件暂不支持使用平台标准控件！

自定义控件暂不支持使用平台标准控件！  
但是自定义控件支持使用标准表单，怎么使用？请往下看

## 如何使用

首先要明确两个概念  
1、elementId：自定义控件里面的元素id，也就是你需要把表单插入到自定义控件的某个节点元素的id  
2、targetKey：自定义控件id  
自定义控件嵌入表单是通过showForm指令的方式，类型为InContainer  
插件示例：
    
    
    FormShowParameter parameter = new FormShowParameter();

    parameter.getOpenStyle().setShowType(ShowType.InContainer);
    parameter.getOpenStyle().setTargetKey('自定义控件id');
     
    Map<String, String> customParams = new HashMap<>();
    customParams.put("elementId", '自定义控件里面的元素id');
    parameter.getOpenStyle().setCustParam(customParams);
     
    this.view.showForm(parameter);

### 1、使用NodeJS的express模块起一个静态资源服务
    
    
    // server.js
    const express = require("express"); // npm i --save express
    const app = express();
    const path = require('path')
    const serveIndex = require('serve-index'); // npm i --save serve-index
     
    //设置跨域访问
    app.all('*', function (req, res, next) {
     // 设置可以跨域访问的域名，比如https://feature.kingdee.com:2024
     res.header('Access-Control-Allow-Origin', 'https://feature.kingdee.com:2024');
     res.header('Access-Control-Allow-Credentials', true);

    });

    app.use('/', express.static(path.join(__dirname, './src/web')));

    })
