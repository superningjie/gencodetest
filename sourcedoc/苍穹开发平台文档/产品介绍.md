# 1.总体介绍

金蝶云苍穹低代码开发平台是国内首款基于云原生架构的、面向企业级业务的、完全自主可控的国内领先的**企业级低代码开发平台** 。

企业管理信息系统作为一类重要的应用软件系统，具有自己的特点，主要有两个方面：

1\. 系统规模大，目前市场上常见的ERP系统一般都有几千个页面。

2\. 页面逻辑相似性强。经过比较可以发现，大部分页面具有类似的功能，以数据的录入，修改，显示为主。

基于企业管理系统的这两个方面的特点，金蝶云苍穹·开发平台结合金蝶在企业管理软件研发二十多年的平台化实践，在传统的粗粒度的领域模型的基础上，以模块上的基本元素为研究对象，提出了ERP动态领域模型的概念，作为解决云端低代码开发大型企业管理信息系统的平台理论基础。

![](https://vip.kingdee.com/download/0109eb2f680437a74bf484e5b85c22edb071.png)

开发平台以苍穹后台核心服务及前端渲染引擎为底座，打造核心的动态领域模型服务。对外提供Web开发工具、插件开发框架、自动化运维平台、服务管理平台等功能，帮助开发者快速完成表单建模、报表建模、[流程](https://www.kingdee.com/products/cosmic_process_service.html?utm_source=shequ )建模、打印设计、权限管理、开放平台等服务。

其中：动态领域模型服务为开发平台建模的核心。

# 2.动态领域模型介绍

KDDM（Kingdee Dynamic Domain Model）：金蝶动态领域模型的简称，是金蝶在二十多年企业级软件研发过程中，通过对成千上万个业务场景沉淀和抽象，结合企业架构（EA）、模型驱动架构（MDA）、领域驱动设计（DDD）等企业建模思想，采用云原生、AI等先进技术研发的一套企业动态建模体系和方法论，解决了企业级软件研发效率、一致性、安全、共性与个性、IT资产化的一系列难题，是[低代码平台](https://www.kingdee.com/products/cosmic_development_services.html?utm_source=shequ )的核心基础。它可以帮助企业从业务场景出发到敏捷IT落地的全过程实现，并不断以模型沉淀企业业务能力。

![](https://vip.kingdee.com/download/0109ab39be2f31874591b9a2ba59b6ad92ed.png)

  * 动态领域模型总体上由模型库、领域模型，领域模型动态解释引擎、可视化动态领域建模工具、领域构建、企业服务等部分组成。

  * 每种模型由多种元素组成，元素又包括多个属性。使用模型-元素-属性三层体系结构来细化模型的粒度，从而描述ERP系统中不同的需求。




以动态领域模型为基础的开发平台，使得系统的80%功能可以使用平台以所见即所得的方式进行设计实现，不需要修改代码。还有20%的功能以插件的方式来实现。插件通过实现系统接口的方式参与既定逻辑，完成特定功能。
