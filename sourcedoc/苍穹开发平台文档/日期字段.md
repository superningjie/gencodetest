    ### 4.3.1 格式化
    在V7.0.1及以上版本，将原来的“掩码”以及“格式化字符串“属性合并为“格式化”属性，用于设置日期控件的交互形态及已选日期的显示格式。
    常见的格式化字符串为: yyyy-MM, yyyy 等。
    
    # 5 日期接口介绍
    ## 5.1 控件编程模型
    ### 5.1.1 控件编程模型定义
    日期字段的控件编程模型是DateEdit，派生自长日期字段的控件编程模型DateTimeEdit：
    ```java
    package kd.bos.form.field;
    public class DateEdit extends DateTimeEdit implements ICloseCallBack {}
    
    ```
    ### 5.1.2 控件方法清单
    DateEdit重写了基类DateTimeEdit的很多方法，修改了日期格式字符串为”yyyy-MM-dd”，去掉了时分秒；
    
    DateEdit重写、新增的方法：
    
    | 方法 | 来源 | 说明 |
    | --- | --- | --- |
    | closedCallBack | 新增 | 接收回调处理 |
    | focus | 重写 | 打开日期范围录入浮层 |
    | getFormatString | 重写 | 输出日期格式掩码，默认为”yyyy-MM-dd” |
    | getIsStartDate | 重写 | 是否为日期范围中的开始日期 |
    | getRelatedDate | 重写 | 输出日期范围中的另外一个日期字段标识 |
    | postBack | 重写 | 接收前端传回的日期字段值 |
    | setFormatString | 重写 | 设置日期格式化串 |
    | setIsStartDate | 重写 | 设置是否设置了开始日期 |
    | setMaxDate | 重写 | 设置前端控件最大可选日期 |
    | setMinDate | 重写 | 设置前端控件最小可选日期 |
    | setRelatedDate | 重写 | 设置相关联日期 |
    
    
    ## 5.2 数据模型
    ### 5.2.1 属性对象
    日期字段运行时，主实体模型中的属性对象类型为DateProp，派生自长日期 DateTimeProp：
    ```java
    package kd.bos.entity.property;
    public class DateProp extends DateTimeProp {}
    
    ```
    DateProp重写、新增的方法：
    
    | 方法 | 来源 | 说明 |
    | --- | --- | --- |
    | getClientType | 重写 | 获取前端控件类型 |
    | getDateFormat | 重写 | 获取日期格式化信息 |
    | getDbType | 重写 | 获取数据库字段类型 |
    | getFilterControlType | 重写 | 获取过滤控件类型 |
    
    
    ### 5.2.2 字段值
    日期字段值是Date类型，时分秒被设置为0，如’2025-09-25 00:00:00‘。
    取值、赋值的处理逻辑，与长日期字段一致，请参阅[长日期的数据模型](https://vip.kingdee.com/article/229171379134639872)介绍。
    ## 5.3 单据体分录行设置
    在单据体内，日期字段支持对每一行设置格式化和日期选择范围。
    设置格式化和日期选择范围的处理逻辑，与长日期字段一致，请参阅[长日期的单据体分录行设置](https://vip.kingdee.com/knowledge/229171379201748736?productLineId=29&isKnowledge=2&lang=zh-CN)介绍。
    
    ## 5.4 插件事件
    日期字段继承了字段值改变事件，未增加其他插件事件。

    package kd.bos.form.field;

### 5.1.2 控件方法清单

getRelatedDate | 重写 | 输出日期范围中的另外一个日期字段标识  
postBack | 重写 | 接收前端传回的日期字段值

### 4.3.1 格式化

在V7.0.1及以上版本，将原来的“掩码”以及“格式化字符串“属性合并为“格式化”属性，用于设置日期控件的交互形态及已选日期的显示格式。  
常见的格式化字符串为: yyyy-MM, yyyy 等。

# 5 日期接口介绍

## 5.1 控件编程模型

### 5.1.1 控件编程模型定义

日期字段的控件编程模型是DateEdit，派生自长日期字段的控件编程模型DateTimeEdit：
    
    
    package kd.bos.form.field;
    public class DateEdit extends DateTimeEdit implements ICloseCallBack {}
    
    

### 5.1.2 控件方法清单

DateEdit重写了基类DateTimeEdit的很多方法，修改了日期格式字符串为”yyyy-MM-dd”，去掉了时分秒；

DateEdit重写、新增的方法：

方法 | 来源 | 说明  
---|---|---  
closedCallBack | 新增 | 接收回调处理  
focus | 重写 | 打开日期范围录入浮层  
getFormatString | 重写 | 输出日期格式掩码，默认为”yyyy-MM-dd”  
getIsStartDate | 重写 | 是否为日期范围中的开始日期  
getRelatedDate | 重写 | 输出日期范围中的另外一个日期字段标识  
postBack | 重写 | 接收前端传回的日期字段值  
setFormatString | 重写 | 设置日期格式化串  
setIsStartDate | 重写 | 设置是否设置了开始日期  
setMaxDate | 重写 | 设置前端控件最大可选日期  
setMinDate | 重写 | 设置前端控件最小可选日期  
setRelatedDate | 重写 | 设置相关联日期  
  
## 5.2 数据模型

### 5.2.1 属性对象

日期字段运行时，主实体模型中的属性对象类型为DateProp，派生自长日期 DateTimeProp：
    
    
    package kd.bos.entity.property;
    public class DateProp extends DateTimeProp {}
    
    

DateProp重写、新增的方法：

方法 | 来源 | 说明  
---|---|---  
getClientType | 重写 | 获取前端控件类型  
getDateFormat | 重写 | 获取日期格式化信息  
getDbType | 重写 | 获取数据库字段类型  
getFilterControlType | 重写 | 获取过滤控件类型  
  
### 5.2.2 字段值

日期字段值是Date类型，时分秒被设置为0，如’2025-09-25 00:00:00‘。  
取值、赋值的处理逻辑，与长日期字段一致，请参阅[长日期的数据模型](https://vip.kingdee.com/article/229171379134639872)介绍。

## 5.3 单据体分录行设置

在单据体内，日期字段支持对每一行设置格式化和日期选择范围。  
设置格式化和日期选择范围的处理逻辑，与长日期字段一致，请参阅[长日期的单据体分录行设置](https://vip.kingdee.com/knowledge/229171379201748736?productLineId=29&isKnowledge=2&lang=zh-CN)介绍。

## 5.4 插件事件

日期字段继承了字段值改变事件，未增加其他插件事件。
