# 2 控件对象

# 4 属性说明

## 4.1 通用属性

> 通用属性包含字段和控件的一些公有的属性，如宽高，帮助文本等等。请参考[通用属性](https://vip.kingdee.com/article/215559076720798976)

## 4.2 样式属性

> 样式属性是每个控件在设计器右侧样式栏可以设置的属性，请参考[样式属性](https://vip.kingdee.com/article/252017936767406336)

## 4.3 业务属性

属性名 | 类型 | 默认值 | 说明 | PC | Mobile  
---|---|---|---|---|---  
掩码 | 文本 | hh-mm-ss | 根据掩码配置倒计时控件显示内容，例如hh-mm-ss、hh-mm、mm-ss | V4.0及以上 | V4.0及以上  
  
# 5 倒计时接口示例

  * 控件方法

方法名 | 参数 | 说明  
---|---|---  
setDuration | int | 设置倒计时时长，单位为秒，设置后会自动开启倒计时  
pause | 无 | 暂停倒计时  
start | 无 | 启动倒计时  
  
  * 设置倒计时时间、暂停倒计时、启动倒计时


    
    
    CountDown countdown = this.getView().getControl('控件标识');*// 设置倒计时时间为70秒*
    countdown.setDuration(70);*// 暂停倒计时*
    countdown.pause()*// 启动倒计时*
    countdown.start()
