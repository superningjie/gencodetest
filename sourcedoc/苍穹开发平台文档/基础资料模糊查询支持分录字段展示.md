特性效果展示

**应用场景**

模糊查询时需要展示分录字段。例如组织的长名称字段位于分录上，在模糊查询的时候，只展示单头的名称字段无法判断具体是哪个组织，故支持插件设置分录字段展示。

  


**功能说明**

  1. 以【组织】基础资料为例进行说明**，** 对【组织】添加一个【个性化控制器】插件并保存，如下图所示：

![上传图片](https://vip.kingdee.com/download/0100d86c2ee945a94e6cbe24af849d859c78.png)




  


******运行效果**

  1. 插件设置显示长名称字段后，效果如下图所示:  


![上传图片](https://vip.kingdee.com/download/010036f795c48eb64b2dbb5ee951b9b7fe92.png)

  





**插件示例代码**
    
    
    import kd.bos.base.IBasedataController;
    import kd.bos.form.field.events.AddFuzzySearchEvent;
    import kd.bos.form.field.events.BaseDataCustomControllerEvent;
    
    
    public class OrgTestPlugin implements IBasedataController {
    
        @Override
        public void buildBaseDataCoreFilter(BaseDataCustomControllerEvent event) {
            
        }
    
        @Override
        public void addFuzzySearchField(AddFuzzySearchEvent event) {
            //单据体字段
            event.addItem("structure.fullname", "长名称", 255.0f); 
        }
    }
