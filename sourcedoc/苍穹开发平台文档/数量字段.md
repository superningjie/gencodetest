    ## 5.2 数据模型
    
    数量字段的属性对象是QtyProp类型，派生自小数字段属性对象DecimalProp，增加了精度控制属性，取单位的数量精度。
    
    ```java
    package kd.bos.entity.property;
    public class QtyProp extends DecimalProp {
    
    ```
    
    数量字段值类型是BigDecimal，存取方式同小数字段，精度取关联的计量单位数量精度。
    
    ## 5.3 插件事件
    
    数量字段，继承了字段值改变事件，未增加新插件事件。
