    # 如何动态修改单据体列标题
    
    
    
    ## 1、应用场景
    
      在某些场景下，需要根据用户选择的信息动态展示单据体列的标题 
    
    
    
    ## 2、功能说明
    
       根据选择的不同，列的标题相应的进行变化
    
    ![image.png](/download/0100622e6e47c1e7404488cd009d32ceddf3.png)
    
    ![image.png](/download/010010a8230e78ac476a993df0dd3478c8a2.png)
    
    ## 3、代码示例
    
    在插件里监听控件点击事件，并动态修改单据体控件列标题名称。
    
    ```java
    package kd.bos.test;
    
    import kd.bos.dataentity.entity.LocaleString;
    import kd.bos.form.ClientProperties;
    import kd.bos.form.control.Control;
    import kd.bos.form.control.EntryGrid;
    import kd.bos.form.plugin.AbstractFormPlugin;
    
    import java.util.EventObject;
    
    public class ModifyEntryGridColumnHead extends AbstractFormPlugin {
    
        @Override
        public void registerListener(EventObject e) {
            this.addClickListeners("bt_moon", "bt_week");
        }
    
        @Override
        public void click(EventObject evt) {
            EntryGrid grid = this.getControl("entryentity");
            Control source = (Control) evt.getSource();
            switch (source.getKey()) {
                case "bt_moon":
                    grid.setColumnProperty("activation",  ClientProperties.Header, new LocaleString("上月活跃度"));
                    grid.setColumnProperty("last_activation",  ClientProperties.Header, new LocaleString("上月活跃度"));
                    break;
                case "bt_week":
                    grid.setColumnProperty("activation",  ClientProperties.Header, new LocaleString("本月活跃度"));
                    grid.setColumnProperty("last_activation",  ClientProperties.Header, new LocaleString("本月活跃度"));
                    break;
            }
        }
    }
    ```
