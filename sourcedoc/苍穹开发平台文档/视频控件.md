    ```
    this.getView().updateControlMetadata('kdtest_videoap', { config: { currentTime: 30} })
    ```

    # 5 视频控件接口示例
    在afterBindData生命中执行以下插件代码，可以给视频控件设置播放地址
    java插件：
    ```java
    public void do() {
        *// 设置视频数据源*
        Video videoCtl = this.getView().getControl("控件id");
        videoCtl.setSrc("https://www.kingdee.com/kingdee/video/kindee1.mp4");
    
        *// 设置自动播放*
        Map<String, Object> dataMap = new HashMap<>();
        dataMap.put("autoPlay", true); *//设置为自动播放*
        dataMap.put("k", "控件id");
        IClientViewProxy proxy = this.getView().getService(IClientViewProxy.class);
        proxy.addAction(ClientActions.updateControlStates, dataMap);
    }
    
    
    
    ```
    
    ts脚本插件
    ```
    class MyPlugin extends AbstractBillPlugIn {
        // Event after data binding
        afterBindData(e: EventObject) {
            super.afterBindData(e);
            //...
        
            let videoCtrl = this.getView().getControl('kdtest_videoap')
            videoCtrl.setSrc('https://www.kingdee.com/kingdee/video/kindee33.mp4')
        
            let dataMap = new HashMap()

            dataMap.put('k', '控件id')

        }
    }
    
    ```

# 4 控件属性说明

## 4.1 通用属性

> 通用属性包含字段和控件的一些公有的属性，如宽高，帮助文本等等。请参考[通用属性](https://vip.kingdee.com/article/215559076720798976)

## 4.2 样式属性

> 样式属性是每个控件在设计器右侧样式栏可以设置的属性，请参考[样式属性](https://vip.kingdee.com/article/252017936767406336)

## 4.3 业务属性

属性名 | 类型 | 运行时参数名 | 默认值 | 说明 | PC | 移动  
---|---|---|---|---|---|---  
文件路径 | string | src | - | 视频文件路径 (支持相对/绝对路径)  
绝对路径：完整的url网址（eg：https://www.youtube.com/embed/u9Mv98Gr5pY）  
相对路径：相对于当前页面的相对地址（eg：tempfile/download.do?configKey=tempfile.mock&id=5431b70d4e114364a6bf7e2ec586078c&appId=kdtest_jinshuo&fId=kdtest_video&pageId=7768d85615a64896b1856f8dfc891cad&kd_cs_ticket=XFU13q3cXpFoHU0udM6J1tO05CkGokDT） | V4.0及以上 | V4.0及以上  
自动播放 | boolean | autoPlay | false | 页面加载后，是否自动播放视频 | V4.0及以上 | V4.0及以上  
视频播放设置 | {  
currentTime: number  
poster: string  
muted: boolean  
volumn: number  
} | config | - | 设置video元素的属性（详情可通过MDN查看属性说明， 需注意autoPlay和loop不支持设置）  
currentTime: 设置视频播放的当前时间  
poster: 设置视频尚未加载或播放时显示的图像URL  
muted: 设置视频是否静音播放  
volumn: 设置视频音量（范围0.0-1.0） | V6.0.12 | V8.0.1  
  
## 4.4 支持视频格式

视频类型 | 视频编码 | 浏览器版本要求  
---|---|---  
Ogg(ogg) | Theora/Vorbis | ‘Firefox 3.5+’, ‘Opera 10.5+’, ‘Chrome 5.0+’  
MPEG4(mp4) | H264/AAC | ‘IE 9.0+’, ‘Chrome 5.0+’, ‘Safari 3.0+’  
WebM(webm) | VP8/Vorbis | ‘Firefox 4.0+’, ‘Opera 10.6+’, ‘Chrome 6.0+’  
  
## 4.5 video元素支持的属性

新增`config` 属性，用户可通过二开插件进行赋值，只要是video元素支持的属性（可通过MDN获取），均能通过config进行写入。如设置视频从特定时间点开始播放，可设置 `currentTime` 属性：
    
    
    this.getView().updateControlMetadata('kdtest_videoap', { config: { currentTime: 30} })

    public void do() {
        *// 设置视频数据源*

        *// 设置自动播放*
        Map<String, Object> dataMap = new HashMap<>();

        IClientViewProxy proxy = this.getView().getService(IClientViewProxy.class);
        proxy.addAction(ClientActions.updateControlStates, dataMap);
    }

    class MyPlugin extends AbstractBillPlugIn {

新增`config` 属性，用户可通过二开插件进行赋值，只要是video元素支持的属性（可通过MDN获取），均能通过config进行写入。如设置视频从特定时间点开始播放，可设置 `currentTime` 属性：
    
    
    this.getView().updateControlMetadata('kdtest_videoap', { config: { currentTime: 30} })

java插件：
    
    
    public void do() {
        *// 设置视频数据源*
        Video videoCtl = this.getView().getControl("控件id");
        videoCtl.setSrc("https://www.kingdee.com/kingdee/video/kindee1.mp4");
    
        *// 设置自动播放*
        Map<String, Object> dataMap = new HashMap<>();
        dataMap.put("autoPlay", true); *//设置为自动播放*
        dataMap.put("k", "控件id");
        IClientViewProxy proxy = this.getView().getService(IClientViewProxy.class);
        proxy.addAction(ClientActions.updateControlStates, dataMap);
    }
